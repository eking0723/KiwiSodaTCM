## **LOGT-001:** Logout Testing  

> **Summary:** Verify that user was able to log out successfully.  <br>

**Preconditions:** User must be logged in.

Scenario 1 

 | \# | Step | Expected Behavior | 
 |----|------|-------------------| 
 |  1 |Click `Profile` dropdown at the right side part of the header    | Verify that a dropdown interface appear   | 
 |  2 |Click `Logout` button      | Verify that the user is redirected to the `Login` page  | 
   

**Post-conditions:**  

 -  User is logged out of the website
